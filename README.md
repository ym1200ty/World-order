# WORLD ORDER — Godot 4.7

لعبة محاكاة عالمية (جيوسياسة + اقتصاد + أسواق + حروب) بخريطة حقيقية، واجهة عربية (RTL) وإنجليزية.

## التشغيل
1. نزّل Godot 4.7 من godotengine.org
2. Import ← اختر `project.godot` ← F5

## التصدير
- كمبيوتر: Project > Export > Windows / Linux (الإعدادات جاهزة في export_presets.cfg) — حمّل Export Templates لـ 4.7 أولاً.
- أندرويد: ثبّت JDK 17 + Android SDK، واضبط مساراتهم في Editor Settings > Export > Android، ثم Export > Android.
  مهم: ملفات `data/*` لازم تفضل مشمولة (include_filter مضبوط بالفعل).

## التحكم
- سحب = تحريك الخريطة | عجلة الماوس / قرصة بإصبعين = زوم
- اضغط محافظة = معلوماتها | اضغط علامة جيش = اختياره (Shift = اختيار أكثر من جيش)
- أمر حركة: اختر جيشاً ثم زر "تحرك" (M) واضغط الوجهة، أو **زر الماوس الأيمن مباشرة**
- Space إيقاف/تشغيل | Tab طبقة الخريطة | 1-6 الشاشات | S إيقاف الجيش | R بناء قاعدة

## الحرب
- الجيوش (مشاة، آلية، مدرعات، مدفعية، قوات خاصة، أسراب طيران، أساطيل، صواريخ) تتحرك محافظة بمحافظة.
- عند اللقاء تبدأ معركة يومية؛ تتحكم فيها بالوضعية (هجومي/متوازن/دفاعي) والتكتيكات
  (تطويق، تحصّن، قصف مدفعي، إسناد جوي، هجوم خاطف) والانسحاب والتعزيز.
- المحافظة لا تتغير إلا بعد أن يسيطر عليها جيشك بلا مقاومة عدة أيام.
- السلام: سلام أبيض / فرض شروط (ضم الأراضي المحتلة) / استسلام. الاحتلال ≠ الضم.
- تجنيد جيوش جديدة، تدريب (مهارة 1-5)، بحث وتطوير (5 فروع)، قواعد في دول حليفة.
- اللعبة تتوقف تلقائياً عند بدء معركة (قابل للإلغاء من القائمة).

## الاقتصاد
- 197 دولة، 4590 محافظة حقيقية، ~1600 شركة (حقيقية لكل دولة + شركات وطنية لكل دولة)، 15 سلعة، 14 عملة رقمية.
- الأسعار تتحرك بسبب: العرض والطلب (منتجون في حرب/تحت عقوبات/احتلال)، معنويات السوق،
  وأوامر البيع والشراء (أوامرك وأوامر صناديق الذكاء الاصطناعي).

## البيانات
الخريطة من Natural Earth (ملك عام). لإعادة توليدها: `python3 tools/build_world.py <مجلد ملفات geojson>`
الملفات المطلوبة: ne_10m_admin_0_countries / ne_10m_admin_1_states_provinces / ne_10m_populated_places_simple

## الهيكل
- scripts/game.gd المحاكاة الأساسية (سياسة، دبلوماسية، حروب، احتلال، اقتصاد شخصي)
- scripts/military.gd الجيوش والمعارك والتكتيكات | scripts/market.gd الأسواق
- scripts/world.gd بيانات العالم | scripts/map_view.gd رسم الخريطة | scripts/main.gd الواجهة
- scripts/lang_ar.gd الترجمة العربية | scripts/tables.gd الشركات والسلع وجداول البيانات
